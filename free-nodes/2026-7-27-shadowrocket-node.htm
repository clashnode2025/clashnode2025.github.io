第一章 下载前的准备工作

1.1 设备兼容性检查

索尼设备涵盖Android手机、Windows笔记本等多条产品线，安装前需确认系统版本：
- Android设备：需运行Android 5.0及以上（如Xperia 1 IV/5 IV等新型号默认兼容）
- Windows设备：推荐Win10/11（VAIO或索尼商务本需检查.NET Framework支持）
小技巧：在Android设置中点击「关于手机」查看系统版本；Windows用户按Win+R输入winver查询。

1.2 官方渠道获取安装包

务必通过Clash官方GitHub仓库（如Clash for Windows）下载，避免第三方修改版的安全风险。针对索尼设备推荐：
- Clash for Android：APK文件约15MB，支持索尼手机的分屏模式
- Clash for Windows：EXE安装包，适配索尼笔记本的高DPI屏幕

第二章 分步安装指南

2.1 Android设备安装流程（以Xperia为例）

  1. 允许未知来源安装：进入「设置→应用和通知→特殊应用访问」，启用「安装未知应用」权限
  2. 安装APK：通过索尼文件管理器找到下载的APK，点击后按提示完成安装
  3. 首次运行配置：授予VPN连接权限（关键步骤！否则无法代理流量）

2.2 Windows设备安装流程（VAIO/Sony笔记本）

  1. 双击EXE安装包，若出现SmartScreen警告，点击「更多信息→仍要运行」
  2. 安装路径建议选择非系统盘（如D:\Clash），避免权限问题
  3. 安装完成后，在开始菜单生成快捷方式，右键「以管理员身份运行」

注：索尼笔记本若遇到驱动签名问题，需在BIOS中临时禁用Secure Boot

第三章 核心配置详解

3.1 初始设置向导

FAQ

Sing-box 可以替换 Clash 的 YAML 配置吗？
可以。Sing-box 原生支持解析 Clash YAML 配置，并自动转换为自身 JSON 结构。节点和规则基本兼容，但部分脚本和自定义插件可能需要手动调整。
Potatso Lite 支持手动和二维码导入节点吗？
支持。用户可以手动添加节点信息，或者通过扫描节点二维码导入节点。虽然不支持自动订阅更新，但足够满足轻量用户对节点管理和分流的需求。
WinXray 的本地 PAC 模式与全局模式有什么区别？
PAC 模式通过规则文件自动判定哪些域名走代理，能兼顾速度与便利；全局模式则所有流量都通过代理，适合调试或访问被完全屏蔽的网络。两者可在界面一键切换，根据需求灵活选择。
Sing-box 支持哪些类型的分流规则？
Sing-box 支持域名、IP、端口、协议类型、用户标签等多种分流规则。结合策略组，可实现精细化流量管理，满足视频加速、广告屏蔽和游戏优化等多样化需求。
Mihomo 节点分组管理有哪些优势？
节点可按地区、延迟或用途分类，结合策略组实现自动分流。便于管理大量节点，快速选择最优节点，提高访问速度和连接稳定性，同时优化维护效率和网络体验。
Sing-box 如何实现流量精细分流？
通过定义 routing 规则和策略组，Sing-box 可以根据域名、IP、端口或协议类型精细分流流量。例如视频走高速节点，网页走备用节点，实现流量优化和网络加速。
SSR 混淆方式如何提升抗封锁能力？
混淆方式可将流量伪装成正常 HTTPS 或 HTTP 数据，降低被 DPI 检测风险。合理选择协议和混淆组合，可以提升节点稳定性和长期可用性，确保科学上网顺畅。
Hysteria2 多路复用如何优化短连接性能？
多路复用允许多个短连接共享同一通道，减少握手延迟和资源消耗。适用于游戏、即时通讯等高频短连接场景，提高吞吐量和连接稳定性，优化整体网络体验。
VLESS 的 Reality 模式需要额外配置吗？
Reality 模式需要配置伪装域名、公钥和服务器指纹等参数。正确配置后，可有效隐藏流量特征，提高在高封锁环境下的可用性和安全性。
Shadowrocket 如何处理域名直连与代理的冲突？
在 Shadowrocket 的规则管理中优先设置具体规则（如 DOMAIN-KEYWORD 或 DOMAIN-SUFFIX），将直连规则放在规则列表靠前位置，避免被泛用的代理规则覆盖，从而确保特定域名走直连。
